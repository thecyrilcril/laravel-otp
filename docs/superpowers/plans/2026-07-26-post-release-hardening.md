> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. (This run: executed inline by the controller — three bounded fixes.) Steps use checkbox syntax.

**Goal:** Close the three follow-ups deferred by the v0.1.0 final review: exercise `lockForUpdate` on a real-locking engine in CI, flatten the `NotFound` timing oracle, and mask the plaintext code under `json_encode`.

**Architecture:** No API changes. One CI job addition + `TestCase` env-awareness; one internal branch in `HasOtps::failureReasonFor()`; one interface implementation on `IssuedOtp`. Tag `v0.1.1` when green.

## Global Constraints

- No public API signature changes — this is a patch release.
- The full gate (`composer ci`) must stay green on sqlite AND the suite must pass on MySQL 8 (locally via Herd MySQL, then in CI).
- Plaintext codes must never appear in any serialization channel after Fix C: `var_dump`, `dump()`, `print_r` of `__debugInfo()`, and now `json_encode`.
- The dummy hash for Fix B must be generated by the runtime hasher (memoized), NOT a hardcoded literal — testbench uses bcrypt cost 10, production default is 12; a literal at either cost mismatches the other environment and re-opens a (smaller) timing gap.
- Forward-only: no migration changes needed by any fix.

### Task B: Flatten the NotFound timing oracle

**Files:**
- Modify: `src/Concerns/HasOtps.php`
- Test: existing NotFound-path tests cover behavior; timing itself is not unit-testable (noted per plan convention)

**Interfaces:** none changed.

**Approach:** in `failureReasonFor()`, the `$otp === null` branch currently returns immediately — the only failure path with no bcrypt work, so "no active code" is distinguishable from "wrong code" by response time (leaks e.g. "a password reset is pending"). Add, before returning `NotFound`:

```php
// Directional: burn one Hash::check against a memoized dummy hash made by
// the runtime hasher, so cost matches the configured bcrypt rounds.
Hash::check($code, self::$timingDummyHash ??= Hash::make('...fixed seed string...'));
```

with `private static ?string $timingDummyHash = null;` on the trait. First NotFound per process pays make+check; subsequent ones match the CodeMismatch path's single check.

- [ ] Step 1: implement; run `vendor/bin/pest tests/VerifyOtpTest.php tests/ConsumeOtpTest.php tests/HardeningTest.php` — green (NotFound behavior unchanged: bare false + NotFound event)
- [ ] Step 2: `composer ci`, commit `fix: equalize NotFound timing with a dummy hash check`

**Test expectation:** behavioral coverage via existing NotFound tests; the new line executes on that path (coverage gate proves it). Timing deltas are not assertable in unit tests.
